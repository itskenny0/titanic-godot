# Third-party software

This native restoration uses [dreamREfactory](https://github.com/dhobi/dreamrefactory), revision `b43a02668f3db36519bd5b44a5892fdefd292208` (Titanic 0.9.67), by Daniel Hobi and contributors. Its engine is licensed under GPL-3.0; the decoder derives from M3tox's DFET. Reverse-engineering credits include M3tox and MRXstudios. The bundled source archive and GPL license are in the application Resources/Licenses directory.

The new native restoration integration sources are provided under GPL-3.0 to match the engine. The pre-existing Wine/scaler scripts retain their original MIT license.

Titanic: Adventure Out of Time and all original game data belong to their respective rights holders. The public runtime includes no commercial game data, saved games, manuals, box artwork, or executable-extracted cursor images. Users import their own game discs for local play. An optional private build can package locally supplied discs and save seeds; it is not a redistributable release. This is an unofficial preservation project.

The public app icon is original vector artwork generated by the included AppKit source. Public cursors use system cursor shapes. New saved games use an authored, zero-initialized format envelope and the restoration's complete state extension, without an original saved-game template.
