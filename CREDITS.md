The game interpreter, file decoders, navigation, animation, conversation, and audio decoding are ported to Go from this engine. Revision: `b43a02668f3db36519bd5b44a5892fdefd292208`. Its upstream credits also acknowledge assistance from Claude Opus and Claude Fable.

The requested [v1.0.3 FULL patch archive](https://github.com/M3tox/TAOOT/releases/tag/v1.0.3) is downloaded or imported and verified by the player. Personal builds bundle it for offline use. Its original README is retained in `godot/patches/README.upstream.txt`. Optional lounge and extended-content mods can be supplied separately. Patch content is not relicensed as original work of this port.
